# Changesets

Hello and welcome! This folder contains Changeset markdown files generated by running `pnpm changeset`.

When you submit a PR that touches `packages/doodle-ui`:
1. Run `pnpm changeset` from the monorepo root.
2. Select `doodleui-react`.
3. Choose semver bump type (`patch`, `minor`, or `major`).
4. Enter a concise description of what changed.
5. Commit the generated markdown file alongside your changes.
