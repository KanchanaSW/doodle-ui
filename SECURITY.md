# Security Policy

## Supported Versions

Security fixes are applied to the **latest** published release of `doodleui-react` only.

| Version | Supported |
| ------- | --------- |
| 0.7.x   | Yes       |
| < 0.7   | No        |

Older minor lines do not receive backported security patches. Upgrade to the latest release when a vulnerability is disclosed.

## Reporting a Vulnerability

**Do not open a public GitHub issue** for security vulnerabilities. Public disclosure before a fix is ready can put users at risk.

Please report vulnerabilities privately using one of these channels:

1. **GitHub Security Advisories** (preferred): [Report a vulnerability](https://github.com/KanchanaSW/doodle-ui/security/advisories/new) on this repository
2. **Email**: sachithrakanchana.ks@gmail.com

Include as much detail as you can:

- Description of the vulnerability and its impact
- Steps to reproduce, or a proof of concept
- Affected package version(s)
- Suggested fix, if you have one

## What to Expect

- You should receive an initial response within **48 hours**
- We will confirm the issue, assess severity, and work on a fix
- A patched release will be published as soon as a fix is ready
- We will credit reporters who wish to be acknowledged (unless you prefer to remain anonymous)

Thank you for helping keep doodleui-react and its users safe.
