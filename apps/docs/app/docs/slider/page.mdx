# Slider

Radix slider with a wobbly track line and a sketch thumb. The filled range is a second, rougher stroke.

<ComponentPlayground name="slider" />

## Usage

```tsx
import { Slider } from "doodleui-react";

<Slider defaultValue={[40]} min={0} max={100} />
```

Pointer, keyboard, and `aria-valuenow` come from Radix. doodle-ui only skins the track and thumb.
