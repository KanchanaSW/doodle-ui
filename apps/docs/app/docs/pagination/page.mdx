# Pagination

Sketch-circled page buttons with a heavier active ring. Prev/next use hand-drawn arrows.

<ComponentPlayground name="pagination" />

## CLI install

<ComponentCliInstallTabs name="pagination" />

## Usage

```tsx
import { Pagination } from "doodleui-react";

<Pagination page={2} count={8} onPageChange={setPage} />
```

The current page sets `aria-current="page"`. The nav is labeled "Pagination".
