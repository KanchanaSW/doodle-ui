## Usage

```tsx

<HoverCard>\n  <HoverCardTrigger asChild>\n    <Button variant="outline">Hover</Button>\n  </HoverCardTrigger>\n  <HoverCardContent>Details</HoverCardContent>\n</HoverCard>
```
