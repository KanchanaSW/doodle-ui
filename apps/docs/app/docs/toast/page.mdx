# Toast

Radix toast with Alert-like sketch chrome. Wrap the tree in `ToastProvider` for stacking, auto-dismiss, and the live region.

<ComponentPlayground name="toast" />

## CLI install

```bash
npx doodleui-react add toast
```

## Usage

```tsx
import { Toast, ToastProvider, Button } from "doodleui-react";

<ToastProvider>
  <Button onClick={() => setOpen(true)}>Show toast</Button>
  <Toast open={open} onOpenChange={setOpen} variant="success" title="Saved">
    The sketch is in the notebook.
  </Toast>
</ToastProvider>
```

ARIA live region, duration, and swipe come from Radix. Entry slides in with a short sketchy settle wobble and reverses on exit. Set `animate={false}` for an instant card.
