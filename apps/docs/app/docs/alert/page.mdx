# Alert

Callout with a color-coded stroke: info, warning, error, success. Body copy stays ink-colored so it stays readable. The frame draws in quickly (~200ms) so dynamic alerts still feel sketched.

## Usage

```tsx
import { Alert } from "doodleui-react";

<Alert variant="warning" title="Heads up">
  Seed values lock screenshots. Shuffle is for demos.
</Alert>
```
