# Checkbox

Radix checkbox with a sketch square. The checkmark is a rough.js path, not a font glyph. The box draws in on mount; the checkmark path draws in when checked.

<ComponentPlayground name="checkbox" />

## CLI install

<ComponentCliInstallTabs name="checkbox" />

## Usage

```tsx
import { Checkbox } from "doodleui-react";

<Checkbox label="Keep the wobble" defaultChecked />
```

Keyboard, mixed state, and `aria-checked` come from Radix. doodle-ui only skins the box.
