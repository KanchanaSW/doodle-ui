# Badge

Compact label with a sketch rectangle. Use it for status, counts, or a one-word tag. The border draws in on mount.

<ComponentPlayground name="badge" />

## CLI install

```bash
npx doodleui-react add badge
```

## Usage

```tsx
import { Badge } from "doodleui-react";

<Badge variant="accent">sketch</Badge>
```
