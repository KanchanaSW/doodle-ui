# Input Group

One sketch frame wrapping an input and addons.

<ComponentPlayground name="input-group" />

## CLI install

```bash
npx doodleui-react add input-group
```

## Usage

```tsx
import { InputGroup, InputGroupAddon, InputGroupInput } from "doodleui-react";

<InputGroup>\n  <InputGroupAddon>@</InputGroupAddon>\n  <InputGroupInput placeholder="user" />\n</InputGroup>
```
