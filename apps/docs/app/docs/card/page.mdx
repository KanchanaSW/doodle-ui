# Card

Container with a sketch border. Optional offset rectangle behind it reads as a paper shadow. The border draws in on mount.

<ComponentPlayground name="card" />

## CLI install

<ComponentCliInstallTabs name="card" />

## Usage

```tsx
import { Card } from "doodleui-react";

<Card title="Field notes" shadow>
  A container with a sketch border.
</Card>
```

Cards do not bundle drop-shadow CSS. The shadow is another rough.js rectangle, translated a few pixels.
