# Card

Container with a sketch border. Optional offset rectangle behind it reads as a paper shadow. The border draws in on mount.

<ComponentCliInstallTabs name="card" />

## Usage

```tsx
import { Card } from "doodleui-react";

// Compound (preferred)
<Card>
  <Card.Header>
    <Card.Title>Field notes</Card.Title>
    <Card.Description>Optional subtitle</Card.Description>
  </Card.Header>
  <Card.Content>A container with a sketch border.</Card.Content>
  <Card.Footer>Actions</Card.Footer>
</Card>

// Legacy props still work
<Card title="Field notes" footer="Actions" shadow>
  Body
</Card>

// Polymorphic root
<Card asChild>
  <article>…</article>
</Card>
```

Named exports (`CardHeader`, `CardTitle`, …) are also available. Cards do not bundle drop-shadow CSS — the shadow is another rough.js rectangle.
