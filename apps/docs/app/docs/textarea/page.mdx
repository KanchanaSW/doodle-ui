# Textarea

Same treatment as Input, sized for longer notes. The sketch rectangle resizes with the element. Focus re-inks the border with a second seed.

<ComponentPlayground name="textarea" />

## CLI install

```bash
npx doodleui-react add textarea
```

## Usage

```tsx
import { Textarea } from "doodleui-react";

<Textarea label="Note" rows={5} />
```
