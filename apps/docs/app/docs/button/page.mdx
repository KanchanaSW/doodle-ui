# Button

A clickable control. The label is real HTML. The border and fill are a rough.js rectangle sitting behind it.

The border draws itself in on mount, then re-inks with a second seed on hover. Toggle `animate` in the playground to compare. See [Animation](/docs/animation) for the library-wide pattern.

## Usage

```tsx
import { Button, DoodleUIProvider } from "doodleui-react";

<DoodleUIProvider>
  <Button variant="primary" size="md">
    Draw me
  </Button>
  <Button asChild>
    <a href="/docs">Docs link</a>
  </Button>
  <Button loading>Saving…</Button>
  <Button startIcon={<Icon />} aria-label="Add" />
  <Button animate={false}>Static sketch</Button>
</DoodleUIProvider>
```

Primary and secondary use hachure fills. Outline is stroke-only. Ghost hides the stroke until hover.

See [Sizing](/docs/sizing), [Icons](/docs/icons), and [Forms](/docs/forms) for shared conventions.
