# Skeleton

A scribble-fill placeholder. Pulse reseeds the hatch on an interval so the doodle redraws instead of shimmering.

<ComponentPlayground name="skeleton" />

## CLI install

<ComponentCliInstallTabs name="skeleton" />

## Usage

```tsx
import { Skeleton } from "doodleui-react";

<Skeleton variant="rect" height={72} />
<Skeleton variant="text" />
<Skeleton variant="circle" />
```

Marked `aria-hidden`. Pair it with Progress or Stepper while real content loads.
