# Switch

Radix switch with a sketch pill track and a circular thumb that slides.

<ComponentPlayground name="switch" />

## Usage

```tsx
import { Switch } from "doodleui-react";

<Switch label="Keep the wobble" defaultChecked />
```

Checked state, keyboard, and `aria-checked` come from Radix. doodle-ui draws the track and thumb.
