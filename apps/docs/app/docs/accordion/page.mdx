# Accordion

Radix accordion with sketch dividers between items and a hand-drawn chevron that rotates on expand.

<ComponentCliInstallTabs name="accordion" />

## Usage

```tsx
import {
  Accordion,
  AccordionItem,
  AccordionTrigger,
  AccordionContent,
} from "doodleui-react";

<Accordion defaultValue="one">
  <Accordion.Item value="one">
    <Accordion.Trigger>What is a seed?</Accordion.Trigger>
    <Accordion.Content>A number that locks the wobble.</Accordion.Content>
  </Accordion.Item>
</Accordion>

{/* Named exports also work */}
<AccordionItem value="two">…</AccordionItem>
```

Keyboard, collapse, and ARIA come from Radix. doodle-ui draws the rules and the chevron. See [Controlled state](/docs/controlled-uncontrolled).
