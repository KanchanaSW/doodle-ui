# Navigation Menu

Horizontal navigation with sketch dropdown panels.

<ComponentPlayground name="navigation-menu" />

## CLI install

```bash
npx doodleui-react add navigation-menu
```

## Usage

```tsx
import { NavigationMenu, NavigationMenuList, NavigationMenuItem, NavigationMenuTrigger, NavigationMenuContent } from "doodleui-react";

<NavigationMenu>\n  <NavigationMenuList>\n    <NavigationMenuItem>\n      <NavigationMenuTrigger>Product</NavigationMenuTrigger>\n      <NavigationMenuContent>...</NavigationMenuContent>\n    </NavigationMenuItem>\n  </NavigationMenuList>\n</NavigationMenu>
```
