# Progress

Outer sketch bar plus an inner fill drawn with slightly higher roughness, so it looks hand-filled. The track draws in on mount. Changing `value` animates the fill width and redraws the hatch a little rougher as it fills.

<ComponentPlayground name="progress" />

<ComponentCliInstallTabs name="progress" />

## Usage

```tsx
import { Progress } from "doodleui-react";

<Progress value={62} max={100} />
```

Exposes `role="progressbar"` with `aria-valuenow`, `aria-valuemin`, and `aria-valuemax`.
