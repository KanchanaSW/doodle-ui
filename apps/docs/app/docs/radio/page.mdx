# Radio

Sketch circle with a solid inner dot when selected. Must live inside `RadioGroup`. The ring draws in on mount; the dot scales and draws in on select.

<ComponentPlayground name="radio" />

## CLI install

```bash
npx doodleui-react add radio
```

## Usage

```tsx
import { RadioGroup, Radio } from "doodleui-react";

<RadioGroup defaultValue="pen">
  <Radio value="pen" label="Pen" />
  <Radio value="pencil" label="Pencil" />
</RadioGroup>
```

## Props

`RadioGroup` accepts the Radix root API (`value`, `onValueChange`, `orientation`, `disabled`). Sketch props live on each `Radio`.
