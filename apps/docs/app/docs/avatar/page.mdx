# Avatar

Radix avatar with a sketch circular or square frame. Falls back to initials, with an optional status dot.

<ComponentPlayground name="avatar" />

## CLI install

<ComponentCliInstallTabs name="avatar" />

## Usage

```tsx
import { Avatar } from "doodleui-react";

<Avatar fallback="AL" alt="Ada Lovelace" status="online" />
```

Image loading and the fallback swap come from Radix. doodle-ui draws the frame and the status badge.
