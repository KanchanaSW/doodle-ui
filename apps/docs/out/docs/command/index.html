Command

A command palette / cmd+k style searchable list, powered by cmdk inside a sketch-bordered panel.

  <CommandInput placeholder="Search tools…" />
  <CommandList>
    <CommandEmpty>No results.</CommandEmpty>
    <CommandGroup>
      <CommandItem value="Pen">Pen</CommandItem>
      <CommandItem value="Pencil">Pencil</CommandItem>
    </CommandGroup>
  </CommandList>
</Command>

CLI install

npx doodleui-react add command

Usage

import {
  Command,
  CommandInput,
  CommandList,
  CommandEmpty,
  CommandGroup,
  CommandItem,
} from "doodleui-react";

<Command>
  <CommandInput placeholder="Search tools…" />
  <CommandList>
    <CommandEmpty>No results.</CommandEmpty>
    <CommandGroup>
      <CommandItem value="Pen">Pen</CommandItem>
      <CommandItem value="Pencil">Pencil</CommandItem>
    </CommandGroup>
  </CommandList>
</Command>

CommandSeparator (a drawn line) and CommandShortcut (a muted trailing caption) round out the set. See Combobox for a ready-made searchable select built on top of Command + Popover.
