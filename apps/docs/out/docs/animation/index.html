Animation

Sketch strokes draw themselves in on mount. Interactions re-ink with a second seed. Everything is on by default and opt-out.

Defaults

Wrap the tree once. Per-component animate wins when it is set. prefers-reduced-motion: reduce disables animation unless the provider sets forceAnimate.

import { DoodleUIProvider, Button, Card } from "doodleui-react";

<DoodleUIProvider>
  <Button>Draws in</Button>
  <Card animate={false}>Static sketch</Card>
</DoodleUIProvider>

<DoodleUIProvider animate={false}>
  <Button>Static unless you pass animate</Button>
  <Button animate>Forced on</Button>
</DoodleUIProvider>

Toggle animate on any component playground to compare the animated sketch with the instant one.

Components

| Component | Mount | Interaction | | --- | --- | --- | | Button | Border draw-in | Seed-morph on hover | | Card | Border draw-in | — | | Badge | Border draw-in | — | | Alert | Border draw-in (~200ms) | — | | Divider | Line extends across its length | — | | Table | Row rules, staggered | — | | Input / Textarea | Border draw-in | Seed-morph on focus | | Checkbox | Box draw-in | Checkmark path draws on check | | Radio | Ring draw-in | Dot scales and draws on select | | Progress | Track draw-in | Fill width + roughness redraw on value | | Tooltip | Bubble draw-in (~180ms) | — | | Select | Trigger draw-in | Popover border draws on open | | Tabs | Active underline draw-in | Underline redraws and slides | | Modal | Panel border draw-in | Backdrop fade + panel enter/exit | | Switch | Track draw-in | Thumb spring + track seed-morph | | Toast | Border draw-in | Slide + settle wobble; reverse on exit |

Set animate={false} (or wrap in DoodleUIProvider animate={false}) to render the final sketch immediately, with no dash leftover and no motion.
