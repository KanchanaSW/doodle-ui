# doodle-ui examples

Runnable starter templates for [`doodleui-react`](https://www.npmjs.com/package/doodleui-react).

| Folder | Description |
| --- | --- |
| [`nextjs-starter`](./nextjs-starter) | Next.js 14 App Router + Shuffle |
| [`vite-react-starter`](./vite-react-starter) | Vite + React + TypeScript |
| [`showcase`](./showcase) | Kitchen-sink composition of most components |

Each example is a standalone package (own `pnpm-workspace.yaml`) so StackBlitz / CodeSandbox can import a single folder from GitHub.
